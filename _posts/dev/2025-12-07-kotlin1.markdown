## 코틀린과 자바의 주요 차이점 정리

|항목|자바|코틀린|
|----|----|----|
|기본 문법|세미콜론 사용|세미콜론 사용하지 않음|
|변수 선언의 차이|long, int 등|val, var|
|메소드 선언|public int max(int a, int b)|fun(str: String, num: Int = 3, useNewLine: Boolean = true)|
|Null 처리|NULL인 경우 Runtime 오류 발생|기본적으로 NULL 값 허용 불가|
|Text Block|str.append 메소드 사용|val str = """ <br> AAA <br> BBB <br>"""|
|동등성 체크|equals 사용|=== 사용|
|하나의 결과 리턴시|return "P"|"P"|
|for문 사용시|for(int i=0; i<3; i++)|for(i in 1..3)|
|throws 사용유무|사용|미사용|
|생성자 사용시|public 클래스명(변수)|constructor(name: String): this(name, 1)|
|클래스 상속|extends 클래스명| 클래스 선언부 : 클래스명 기입<br>override fun move() 방식으로 메소드 구현 가능|
|VO Class|getter,setter 별도 사용|data class 선언|
|디폴트 접근 지시어|아무것도 선언 안한 상태 (같은 패키지에서 접근)|public이 기본|
|콜렉션 변수 선언|List<Integer> list = Arrays.asList(100,200);|val list = listOf(100,200)|
|싱글톤 선언시|static으로 getInstance 선언 필요|object Singleton { var a: Int = 0}|

다음에는 다른 것으로 돌아오겠습니다!

긴 글 봐주셔서 감사합니다! 😌
